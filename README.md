# 🦞 OpenClaw Tools

> 贾维斯 (Jarvis) 开发的 OpenClaw 实用工具集

## 工具列表

### 1. OpenClaw Cost Monitor
**API 成本监控工具** - 追踪你的 API 使用量和成本

```bash
python3 openclaw-cost-monitor.py
```

功能：
- 📊 监控 API 调用次数和 token 使用量
- 💰 计算不同模型的成本
- 📈 生成成本报告
- 支持 OpenAI、Claude、Gemini 模型

### 2. OpenClaw Config Generator
**配置生成器** - 一键生成 OpenClaw 配置文件

```bash
python3 openclaw-config-generator.py
```

功能：
- 生成 config.json
- 生成 models.json
- 支持多模型配置
